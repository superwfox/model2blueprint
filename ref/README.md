## 本项目的应用

- 已确认的布局原则：UI 尽可能少占用、少遮挡建筑视口，配置紧凑清晰，状态之间的公共区域、控件行高及高度变化合理连贯；不能为简单配置强行预留大块空白。笔刷共用的大固定高度已移除，当前实现及检查范围见当前摘要，不将本次修正扩大为所有 UI 已完成验收。
- `src/app/style.css`：统一主题变量，背景 `#000000`，麦金色 `#c6b07d`，正文 `#d1c8b6`；上传区、工具栏、表单和面板使用直角细边框。
- `src/app/components/LatticeCorners.vue`：以 Vue SVG 保留参考角花。卡片角花在框外，按钮角花内嵌，均不接收鼠标或键盘事件。
- `src/app/components/UploadArea.vue`：保留窗棂角花的顺序起伏；工作期间随进度加快，接近完成后恢复，隐藏或减少动态效果时停止动画。
- `WorkspaceToolbar.vue` / `HistoryPanel.vue`：下载按钮右侧使用时钟历史入口，沿用容器内展开、黑底金色上箭头及窗棂按钮；历史动态文件名与操作使用本地进步体，长文件名省略并保留完整 title，按钮保持独立内边距。
- `TransientBar.vue` / `NavigationBar.vue`：复用现有窗棂框、按钮、动态字体与间距；移动触发底部滑入，5 秒无刷新滑出，减少动态效果时直接切换。落点选择提示使用带背景的状态框，保留文字四周留白。
- 所有运行滑条在 `style.css` 统一为 2px 细直线轨道、12px 方形滑块与 24px 操作高度；无圆角，颜色继续使用主题变量。步行、飞行速度同栏显示，最长「取消落点选择」按钮保留内边距；ref 中的原始快照不修改。
- `EditorToolbar.vue` 复用顶部窗棂容器、展开按钮和现有完整方块缩略图；新增编辑标签与动态方块名沿用本地内容字体。首页空白入口是独立按钮，未嵌套在上传按钮里。贴面网格与透明预览只存在三维场景，原始参考快照不变。
- 编辑栏已移除切片/退出按钮，笔刷选择与设置合并为一个展开入口，顶部六个直角方块选项；`BrushPanel.vue` / `WallPatternEditor.vue` 复用黑金表单、方块缩略图和内容字体，按钮有独立安全内边距，长文案允许工具栏折行。墙预设在左侧列表、多个结构表单在右侧横排（可横向滚动），节点在下方；由 BrushPanel / WallStructureForm / WallPatternEditor 分工。有效修改自动应用，移除落点 Y，切换选材保留草稿。墙体配置使用类型/序号紧凑卡片，去掉子结构名称和行列输入，预设与追加操作同排；24px 复选框，图内边缘网格负责行列扩展，空气格用棋盘底纹区分；原始设计快照不变。
- 所有笔刷沿用同一紧凑选项尺寸与稳定公共位置，配置按内容撑开、最多 360px 并随视口限高，只有配置区滚动；编辑面板缩小上下留白，笔刷入口预留最长文案宽度。EditorToolbar 测量自然内容并在外层平顺调整高度，切换不保留大块空白；单块连续绘制仍跟随原有表面，预览忽略本笔新增格，网格/形状辅助不写入建筑。
- 墙线已有节点在屏幕 70px 半径内吸附并显示整格、世界轴对齐的金色方块线框，起点同样使用方块线框；辅助路径使用 Three.js 宽线保持 5px。下一点旁用黑底金字提示连接状态和角度，标签有稳定内边距并限制在视口内，不接收指针事件。Alt 45°、Shift 锁高、Ctrl 曲线的提示共用现有内容字体；原始设计快照保持不变。
- 收起时保留当前面板直到高度过渡结束，再释放内容，内部焦点交回入口；正常展开/收起动画完整保留。连续放置不再逐批让工具栏变灰，数量/保存状态使用稳定宽度；最长名称允许整栏折行。图案右键清除会裁去全空白边缘，内部空气和最小一格保留；沿用原黑金主题及内边距。
- `src/adapters/renderer/viewer.ts` 与 `src/adapters/slice.ts`：画布使用同一黑色系，网格使用中性色；Y=0 参考网格为一格间距，整数中心/偶数跨度与方块边界对齐。模型灯光、原始材质与方块贴图保持原有行为。
- `public/fonts/`：复用 Minecrafter，江西拙楷裁切为固定文案字集，钉钉进步体保留来源完整字集，用于材质名、方块名、输入值和处理状态。全部本地加载。

2026-10-31 将运行界面迁移为 Vue，新增依赖已单独获用户确认；四份原始设计快照保持原样。字体验证与更新方式见项目 README，本轮记录见根目录 Changelog。
