# 架构与开发边界

## 当前定位

项目目前是纯静态、浏览器本地处理的 GLB 转换器，面向 Minecraft Java 26.3 / DataVersion 5023，导出 Sponge Schematic v2。Vue 负责界面，Three.js 负责三维显示，计算在 Web Worker 中进行。

后续方向是单人网页方块编辑器；当前包含 Vue 与模块基础、浏览器本地导入历史和完整转换状态恢复，没有实现直接编辑、撤销重做、可交换的编辑项目格式、账户、服务端或多人同步。未经确认不引入这些能力及其依赖。

## 三层职责

| 层 | 入口与职责 | 依赖规则 |
| --- | --- | --- |
| `src/core/` | `geometry` / `voxelize` 处理实体与体素；`block-shapes` 统一形状；`walking` 处理角色包围盒与形状碰撞；`palette` / `colors` / `texture-data` 提供材质数据；`surface` / `falling-data` 生成预览数组；`schem` 编码 NBT；`types` 定义数据 | 仅核心与 JSON 数据，不依赖 Vue、Three.js、DOM 或 adapters |
| `src/adapters/` | `glb` 提取 GLB；`schem` gzip 压缩；`worker/` 定义消息、客户端和执行入口；`renderer/` 管理 Three.js；`history/` 管理 IndexedDB、缓存校验与末次视角；`slice` 绘制 Canvas；`download` 管理浏览器下载 | 可依赖 core 和平台 API，不依赖 app |
| `src/app/` | `App.vue` 组装；`useWorkspace` 编排会话；`useHistory` 管理导入身份、持久化状态与视角节流；组件管理上传、视口、工具栏、材质、切片与历史；`material-options` 为列表提供 UI 数据；`style.css` 保留设计 | 可依赖 core 与 adapters，不把业务计算写进模板 |

`src/main.ts` 仅挂载应用并处理 HMR 卸载。`src/data/` 的两个生成目录、`public/` 素材、离线 Python 工具继续复用；测试与真实模型验证脚本直接导入核心和适配器，无需启动 Vue。

## 数据流与接口

1. 上传组件发出 `File`；会话读取文件，GLB 适配器校验并生成原模场景与 `ModelData`，尺寸校验通过后替换当前模型。
2. 会话以普通对象调用 Worker 客户端。`convert` 进行体素化、静态表面合并和可选掉落数组生成，返回 `ConversionOutput`。
3. 主线程保留 `VoxelResult`，渲染适配器接收预览数组。Vue 提交 ready 状态、加载层淡出后才开始掉落计时。
4. 材质选择先更新映射，`remesh` 仅生成新表面；失败或取消则恢复映射与手动变体标记。几何和统计不重新计算。
5. 切片按四分之一格高度绘制相同的形状定义。`export` 将当前体素和材质编码、压缩，再通过下载适配器保存 `.schem`。

Worker 协议位于 `adapters/worker/protocol.ts`：请求继续使用 `convert / remesh / export`；响应为 `progress`、对应完成结果或 `error`。客户端检查终态与请求匹配，处理线程错误及消息读取失败；同一会话同时只允许一个任务。取消通过终止线程实现，没有线程池或后台队列。

`ModelData` 保存可克隆的网格和源材质；`VoxelResult` 保存尺寸、形状 `Uint8Array`、材质 `Uint16Array` 和统计。索引固定为 `x + z * width + y * width * length`；形状 0 为空气、1/2 为上下半砖、3 为完整方块、4–43 为楼梯、44–47 为展示架。这些编码与 Sponge 导出语义保持不变。

## 状态与资源所有权

- `useWorkspace` 为每次挂载创建独立会话，持有模型、转换结果、材质映射、手动变体标记、状态、文件名和尺寸；大数据用 `shallowRef`，映射按根数组替换更新，不创建全局单例。
- 工具栏持有面板展开状态，材质面板持有搜索词，切片面板持有高度与悬浮信息。视口生命周期独立于面板变化，不因切换面板或更新状态重建。
- Viewer 是非响应式对象，由视口组件创建和释放；它拥有原模场景、相机、控制器、GPU 资源、观察器、纹理与动画帧。没有 WebGL 时，原模场景由会话兜底释放。
- Worker 客户端拥有线程，输入采用结构化克隆以保留可重复使用的主线程缓冲区；输出数组继续使用 transfer，所有权交给主线程。Vue Proxy 不得进入消息。
- 下载适配器负责 URL 与延迟回收定时器；卸载时立即清理。组件管理的全局拖拽、Escape、beforeunload 监听均在卸载时解除；HMR 也执行卸载。
- 会话关闭后，未完成的 GLB 解析返回时只释放场景，不再更新 UI 或发起 Worker 任务；卸载后的 Worker Promise 不再提交结果。

## 导入历史与自动恢复

`adapters/history/database.ts` 使用原生 IndexedDB，数据库 `model2blueprint-history` v1；无新依赖或服务端。每次成功导入并完成转换创建一个 UUID 条目；同一次导入的尺寸重转、材质修改覆盖该条目。原始文件、可克隆 `ModelData`、`VoxelResult`、静态 `SurfaceData`、尺寸输入、材质与手动变体、预览模式及相机位置/观察目标均在恢复范围内；面板展开、搜索、切片交互与掉落动画不持久化。

数据按 `entries`（名称、时间、尺寸、数量、视角）、`sources`（原 GLB Blob 与 ModelData）、`voxels`、`surfaces`、`palettes`、`settings`（当前条目）拆开。历史列表只读小份元数据；源文件只在首次保存时写入，几何只在转换后写入，换材质只更新映射与表面。一次内容更新与当前条目指针使用同一事务，失败时旧快照完整保留；几何写入失败后，后续材质保存也必须补写最新几何，避免表面与结果错配。

视角由 Viewer 汇集 OrbitControls、键盘和第一人称变化通知会话；`useHistory` 每 250 ms 节流写入小份元数据，窗口退出前读取最新视角并刷新。视图可选 `navigationProfiles` 分别保存步行/飞行的水平与垂直速度，保留旧 `navigation` 字段供兼容。读取时优先两组设置；旧共享速度映射为步行设置、不猜测覆盖手动值，飞行补默认 14；无速度数据时使用步行 8、飞行 14，新导入重置到该默认值。可选扩展无需数据库升级。末次视角 localStorage 只保留 ID、时间、模式、相机与速度，作为同步退出补充；只有 ID 匹配且时间较新时使用，不保存模型或体素。缓存内容写入失败后暂停该视图的相机覆盖，直到成功保存或恢复记录。

启动恢复当前条目；当前条目不存在时选择最新导入。读取后先校验格式、DataVersion、数组、尺寸与映射，再替换运行状态；方块模式直接加载缓存静态表面，无 Worker 转换或 GLB 解析。原模按需从缓存 Blob 解析；保存的预览模式为原模时在恢复时解析。Viewer 为恢复提供相机快照和仅附加原模接口，面板操作不重建渲染器。无 WebGL 时仍保留切片、导出与缓存能力。

历史只手动删除，不设条数上限、不自动清理；容量或存储故障提示本次未缓存，不删除旧数据。删除同时清除该条的全部存储，保留当前打开视图；若删除当前条目，该视图脱离自动保存，直到重新导入或恢复其他条目，防止导航或材质操作重建已删记录。损坏或不兼容的建筑数据保留并报错，不静默删除；仅可选相机或速度元数据无效时，恢复建筑并使用适应视图/默认速度。会话不写入无效相机；视口 HMR 替换时先从现存数据重建并恢复相机，再订阅变化，避免默认相机覆盖缓存。浏览器清理站点数据、隐私模式限制或浏览器自身存储回收不属于应用可保证的长期备份。

这些数据是导入缓存格式，`VoxelResult` 仍是转换快照；不作为未来完整编辑项目格式、撤销历史或跨设备同步协议。

## 展开按钮与键盘导航

`renderer/orbit-pinch.ts` 单独处理轨道视图的触摸板缩放：捕获 Ctrl+wheel/WebKit gesture 并避免重复处理，按对数距离累计目标，在 Viewer 现有循环中以帧时间平滑接近，不改变 FOV。普通滚轮仍交给 OrbitControls，避免其额外 10 倍捏合增量叠加页面 3 倍速度。减少动态效果时直接更新距离；控件开始其他操作、失焦、隐藏、选点、适应与恢复清空目标，卸载解除监听。

`ToolButton` 的可选 `expanded` 属性与命名 `icon` 插槽统一展开反馈：展开为黑底、金色向上箭头，收起恢复传入的图标；未传 `expanded` 的普通按钮不改变语义和样式。工具栏负责具体面板状态，并提供对应的 `aria-controls`。

`renderer/keyboard-navigation.ts` 由 Viewer 创建、逐帧更新和释放，复用渲染循环与预分配向量。WASD 按摄像机方位在水平 XZ 平面移动，不受俯仰角影响高度；从水平右向量推导前向量，俯视/仰视时也保持稳定。↑/↓ 单独沿世界 Y 轴升降。摄像机和 OrbitControls 的 target 同步位移，不改变鼠标轨道控制与缩放。

视口组件以 `navigationEnabled` 接收“已有模型且不忙”的状态，传递给 Viewer；只有画布获得焦点时读取移动键，点击画布会获取焦点。处理任务、焦点离开画布、窗口失焦及页面可见性变化均清除按键状态；修饰键组合与输入法组合输入不触发移动。水平组合方向归一化，水平/垂直速度独立，步行及轨道默认 8/8，飞行默认 14/14 blocks/s；模式变化选择对应配置，不重置另一组。步行/飞行切换清除疾跑状态但保留升降按键，避免 ↑ 键进入飞行后失效。每帧时间上限 50 ms，防止恢复显示时跳跃。

350 ms 内双击 W，第二次按住时使用基础水平速度的 1.3 倍；松开 W、按 S、失焦、任务禁用或切换导航模式时结束。共享输入层使轨道平移、步行与飞行均可使用该操作，只加成有前进分量的水平位移，不改变基础速度设置、垂直速度或跳跃重力。此处是本工具的疾跑规则，不实现饥饿、耐力或完整游戏运动系统。

`TransientBar.vue` 是可复用的插槽容器，提供 `refreshKey`、`duration`（默认 5000 ms）、`enabled` 与 show/hide 接口；触发后从底部滑入，内容更新或操作重新计时，超时滑出并变为 inert。容器用 ResizeObserver 通知高度，App 留出状态提示间距，内容折行或第一人称提示出现时不重叠；卸载释放观察器与计时器。`NavigationBar.vue` 同时显示步行和飞行两组，管理共享方向按钮及各组数字草稿，用户无需在锁定鼠标后操作。滑条 1–50，数字接收任意正有限数，不加业务上限，超出滑条范围时仅把滑条显示夹到端点；无效草稿失焦时恢复当前值。Viewer 的移动活动通知最多每 100 ms 一次，不让 Vue 跟随逐帧坐标变化。

所有运行时 `input[type=range]` 共用 `style.css` 的样式：24 px 高的操作区域、2 px 直线轨道与 12×12 px 方形滑块，无圆角，沿用黑金主题；提供 WebKit 与 Gecko 伪元素规则。切片和速度控件只定义布局与尺寸，不各自覆盖轨道或滑块。原始 ref 快照保持不变。

## 第一人称、碰撞与 FOV

入口先进入落点选择并显示有背景的指引，冻结轨道惯性和键盘平移；用户再点击建筑或可见网格内的 Y=0 地面。仅此时进行一次射线拾取并请求鼠标锁定，空白处不使用隐藏无限平面、不复用旧落点；Esc 或再次点击入口取消选择。鼠标锁定失败保留原相机和轨道视图，按用户确认不提供拖动转向降级。成功后角色脚放在选择处，视点高 1.62 格；若身体与建筑重叠，向上腾出站立空间。选点状态与锁定状态不持久化，刷新回到轨道模式并恢复相机位置及朝向。

`renderer/first-person.ts` 组合 Three.js 自带 PointerLockControls 与核心 `walking`。角色包围盒宽 0.6、高 1.8 格；步行使用当前 `VoxelResult` 的完整方块、半砖、楼梯和展示架实际盒形，逐轴扫描移动路径附近格子并限制位移，避免按速度步进导致穿墙，也不分配整世界碰撞副本。Space 地面跳跃（重力 24 格/秒²，目标跳高 1.25 格）；300 ms 内双击 Space 切换飞行，↑/↓ 直接进入飞行升降，飞行时 Space 也可上升。飞行忽略侧面和向上阻挡，下降碰到建筑顶面或 Y=0 地面时落地退出；双击 Space 也可退出飞行，身体处于方块中时先腾出步行空间。

第一人称只改投影的滚轮 FOV 范围为 20°–100°，向上放大、向下缩小；Shift 使用五分之一的调整速率，并统一像素/行/页滚轮单位。`first-person-fov.ts` 独立保存当前站点的全局浏览器偏好，默认 40°；调整时以 250 ms 节流写入 localStorage，退出/失焦/隐藏/卸载刷新待写值，进入时读取记住的值。新模型或历史恢复不覆盖该偏好，不为每条历史保存 FOV。非法或不可用存储回退到会话值，不阻断导航。退出仍恢复进入前的轨道 FOV，不改变轨道模式滚轮缩放。Pointer Lock、滚轮、全局焦点、选择事件均由 Viewer/第一人称控制器释放；处理任务、窗口失焦和隐藏会退出锁定。未引入物理引擎或新的依赖；该功能不包含自动跨台阶或完整 Minecraft 运动复刻。

触摸板缩放在第一人称控制器内同时接收 `ctrlKey` 为真的 `wheel`（Chromium/Firefox）和 WebKit 的 `gesturestart/change/end`。原先过滤 Ctrl 的逻辑会漏掉前者，参见 [MDN wheel 事件说明](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)；WebKit `scale` 是相对手势起点的倍率，参见 [Apple GestureEvent.scale](https://developer.apple.com/documentation/webkitjs/gestureevent/1632653-scale)。手势按倍率调整半视角正切值，张开放大、捏合缩小，沿用范围、Shift 精细调整与全局保存；普通滚轮和双指滚动保持原角度增量。原生 gesture 进行中忽略重复 wheel 缩放，退出清空手势状态，卸载移除全部监听。只在第一人称阻止默认页面缩放，轨道视角不拦截；浏览器将 Ctrl+滚轮与捏合放在同一路径，因此第一人称内两者均调整 FOV。

## 性能与兼容约束

保持输出最多 3200 万格、预览最多 125 万三角面、掉落最多 100 万长方体实例；预算值的实现分别在 `geometry`、`surface` 和 `falling-data`。超预览预算仍可切片和导出，超动画预算或减少动态效果时显示静态结果；贴图失败保留代表色，无 WebGL 时仍可转换、切片与下载。

本轮保留已有算法、采样、贴图、灯光、缩放与持续渲染循环。GLB 读取/场景解析仍在主线程，读取阶段不支持取消；重铺表面仍按整个结果计算。没有新增分块重建、LOD、性能指标采集或帧率承诺。

未来直接编辑应在 core 侧另行设计建筑数据与操作，再由会话、Worker 和渲染器适配；当前 `VoxelResult` 只是导入转换快照。分块、脏区域、撤销重做和项目格式须随具体功能确认，不能预先把渲染 Mesh 当作唯一建筑数据，也不为未实现功能建立空框架。

## 文档与验证

指导入口为根目录 `AGENTS.md`；`LOCAL_HANDOFF.md` 仅保存当前摘要；根目录 `CHANGELOG.md` 保存倒序历史；README 保存使用与素材维护说明。每次实际改动同步最新记录，架构变化更新本文件，避免另建同用途交接文档。

`npm run typecheck` 使用 `vue-tsc --noEmit` 覆盖 `.ts`、SFC 模板、测试、脚本和 Vite 配置；`npm run check` 保留完整测试、类型检查与生产构建。日常按用户约定只做必要静态与桌面视觉检查，部署前执行聚合检查。Axiom 导入和复杂模型验收需单独记录。
