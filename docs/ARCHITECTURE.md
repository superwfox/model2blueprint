# 架构与开发边界

## 当前定位

项目目前是纯静态、浏览器本地处理的 GLB 转换器，面向 Minecraft Java 26.3 / DataVersion 5023，导出 Sponge Schematic v2。Vue 负责界面，Three.js 负责三维显示，计算在 Web Worker 中进行。

当前已包含完整方块笔刷、共享预设墙节点、地表平滑/龟裂、独立本地建筑和可持久化的撤销/重做。尚未包含独立的单格拆除工具、半砖/楼梯放置、可交换编辑项目格式、账户、服务端或多人同步。

## 三层职责

| 层 | 入口与职责 | 依赖规则 |
| --- | --- | --- |
| `src/core/` | `geometry` / `voxelize` 处理实体与体素；`block-shapes` 统一形状；`walking` 处理角色包围盒与形状碰撞；`palette` / `colors` / `texture-data` 提供材质数据；`surface` / `falling-data` 生成预览数组；`schem` 编码 NBT；`types` 定义数据 | 仅核心与 JSON 数据，不依赖 Vue、Three.js、DOM 或 adapters |
| `src/adapters/` | `glb` 提取 GLB；`schem` gzip 压缩；`worker/` 定义消息、客户端和执行入口；`renderer/` 管理 Three.js；`history/` 管理 IndexedDB、缓存校验与末次视角；`slice` 绘制 Canvas；`download` 管理浏览器下载 | 可依赖 core 和平台 API，不依赖 app |
| `src/app/` | `App.vue` 组装；`useWorkspace` 编排会话；`useHistory` 管理导入身份、持久化状态与视角节流；组件管理上传、视口、工具栏、材质、切片与历史；`material-options` 为列表提供 UI 数据；`style.css` 保留设计 | 可依赖 core 与 adapters，不把业务计算写进模板 |

`src/main.ts` 仅挂载应用并处理 HMR 卸载。`src/data/` 的两个生成目录、`public/` 素材、离线 Python 工具继续复用；测试与真实模型验证脚本直接导入核心和适配器，无需启动 Vue。

测试入口沿用 Node 的 `--experimental-strip-types`，核心及其测试依赖使用可直接剥离的类型语法；类字段显式声明并在构造中赋值，不使用需要转译的构造函数参数属性。Vue/渲染适配器仍由 Vite 编译，不为测试额外引入运行依赖或改变最低 Node 版本。

## 数据流与接口

1. 上传组件发出 `File`；会话读取文件，GLB 适配器校验并生成原模场景与 `ModelData`，尺寸校验通过后替换当前模型。
2. 会话以普通对象调用 Worker 客户端。`convert` 进行体素化、静态表面合并和可选掉落数组生成，返回 `ConversionOutput`。
3. 主线程保留 `VoxelResult`，渲染适配器接收预览数组。Vue 提交 ready 状态、加载层淡出后才开始掉落计时。
4. 材质选择先更新映射，`remesh` 仅生成新表面；失败或取消则恢复映射与手动变体标记。几何和统计不重新计算。
5. 切片按四分之一格高度绘制相同的形状定义。`export` 将当前体素和材质编码、压缩，再通过下载适配器保存 `.schem`。

Worker 协议位于 `adapters/worker/protocol.ts`：请求继续使用 `convert / remesh / export`；响应为 `progress`、对应完成结果或 `error`。客户端检查终态与请求匹配，处理线程错误及消息读取失败；同一会话同时只允许一个任务。取消通过终止线程实现，没有线程池或后台队列。

`ModelData` 保存可克隆的网格和源材质；`VoxelResult` 保存尺寸、形状 `Uint8Array`、材质 `Uint16Array` 和统计。索引固定为 `x + z * width + y * width * length`；形状 0 为空气、1/2 为上下半砖、3 为完整方块、4–43 为楼梯、44–47 为展示架。这些编码与 Sponge 导出语义保持不变。

## 状态与资源所有权

UI 遵循主体优先与低侵入布局：三维建筑/画布优先可见，工具栏和配置紧凑呈现当前任务的关键内容，面板占用与有效内容相称。状态之间保持公共区域位置、同类控件行高和舒适的高度衔接，必要的尺寸变化平顺过渡；不得通过简单配置也占据大固定高度来实现一致性。布局检查须覆盖主体可见性以及简单/复杂、展开/收起/切换状态，既有长文案与控件安全边距规则继续适用。实施与检查结果见当前摘要。

- `useWorkspace` 为每次挂载创建独立会话，持有模型、转换结果、材质映射、手动变体标记、状态、文件名和尺寸；大数据用 `shallowRef`，映射按根数组替换更新，不创建全局单例。
- 工具栏通过 `useToolbarPanels` 持有展开状态与当前内容，材质面板持有搜索词，切片面板持有高度与悬浮信息。收起先禁用交互并将内部焦点交回入口，内容保持挂载直至 grid/height 高度过渡结束，再移除/停用；400ms 兜底定时器在重开或卸载时取消，沿用既有系统动态效果偏好，不新增开关。视口生命周期独立于面板变化，不因切换面板或更新状态重建。编辑 Worker 的短批次忙碌只更新数量/保存状态，不切换整栏按钮 disabled；真正的导入/导出等全局任务仍禁用，导出等待命令队列，切换建筑继续受保存/任务保护。保存状态固定留出宽度，避免数字或状态长度变化推动其他控件。

EditorToolbar 通过一个 ResizeObserver 测量内部内容的自然高度，只让外部裁切容器进行 280ms height 过渡，覆盖展开、收起、笔刷设置变化及选材/历史切换；测量对象不受外层动画高度约束，避免尺寸反馈循环，卸载断开观察器。BrushPanel 将选项行与配置滚动区分开，移除共用固定高度，配置自然撑开至 `min(360px, 65dvh - 210px)` 上限；仅配置滚动，选项保持位置，切换笔刷后回到配置顶部。编辑面板压缩上下留白，笔刷入口预留最长文案的固定宽度，保留原主题、字体与控件行高；BrushPanel KeepAlive 草稿和提交逻辑不变。
- Viewer 是非响应式对象，由视口组件创建和释放；它拥有原模场景、相机、控制器、GPU 资源、观察器、纹理与动画帧。没有 WebGL 时，原模场景由会话兜底释放。
- Worker 客户端拥有线程，输入采用结构化克隆以保留可重复使用的主线程缓冲区；输出数组继续使用 transfer，所有权交给主线程。Vue Proxy 不得进入消息。
- 下载适配器负责 URL 与延迟回收定时器；卸载时立即清理。组件管理的全局拖拽、Escape、beforeunload 监听均在卸载时解除；HMR 也执行卸载。
- 会话关闭后，未完成的 GLB 解析返回时只释放场景，不再更新 UI 或发起 Worker 任务；卸载后的 Worker Promise 不再提交结果。

## 导入历史与自动恢复

`adapters/history/database.ts` 使用原生 IndexedDB，数据库 `model2blueprint-history` v2；无新依赖或服务端。原有 v1 导入数据原样保留，建筑扩展见下文。每次成功导入并完成转换创建一个 UUID 条目；同一次导入的尺寸重转、材质修改覆盖该条目。原始文件、可克隆 `ModelData`、`VoxelResult`、静态 `SurfaceData`、尺寸输入、材质与手动变体、预览模式及相机位置/观察目标均在恢复范围内；面板展开、搜索、切片交互与掉落动画不持久化。

数据按 `entries`（名称、时间、尺寸、数量、视角）、`sources`（原 GLB Blob 与 ModelData）、`voxels`、`surfaces`、`palettes`、`settings`（当前条目）拆开。历史列表只读小份元数据；源文件只在首次保存时写入，几何只在转换后写入，换材质只更新映射与表面。一次内容更新与当前条目指针使用同一事务，失败时旧快照完整保留；几何写入失败后，后续材质保存也必须补写最新几何，避免表面与结果错配。

视角由 Viewer 汇集 OrbitControls、键盘和第一人称变化通知会话；`useHistory` 每 250 ms 节流写入小份元数据，窗口退出前读取最新视角并刷新。视图可选 `navigationProfiles` 分别保存步行/飞行的水平与垂直速度，保留旧 `navigation` 字段供兼容。读取时优先两组设置；旧共享速度映射为步行设置、不猜测覆盖手动值，飞行补默认 14；无速度数据时使用步行 8、飞行 14，新导入重置到该默认值。可选扩展无需数据库升级。末次视角 localStorage 只保留 ID、时间、模式、相机与速度，作为同步退出补充；只有 ID 匹配且时间较新时使用，不保存模型或体素。缓存内容写入失败后暂停该视图的相机覆盖，直到成功保存或恢复记录。

启动恢复当前条目；当前条目不存在时选择最新导入。读取后先校验格式、DataVersion、数组、尺寸与映射，再替换运行状态；方块模式直接加载缓存静态表面，无 Worker 转换或 GLB 解析。原模按需从缓存 Blob 解析；保存的预览模式为原模时在恢复时解析。Viewer 为恢复提供相机快照和仅附加原模接口，面板操作不重建渲染器。无 WebGL 时仍保留切片、导出与缓存能力。

历史只手动删除，不设条数上限、不自动清理；容量或存储故障提示本次未缓存，不删除旧数据。删除同时清除该条的全部存储，保留当前打开视图；若删除当前条目，该视图脱离自动保存，直到重新导入或恢复其他条目，防止导航或材质操作重建已删记录。损坏或不兼容的建筑数据保留并报错，不静默删除；仅可选相机或速度元数据无效时，恢复建筑并使用适应视图/默认速度。会话不写入无效相机；视口 HMR 替换时先从现存数据重建并恢复相机，再订阅变化，避免默认相机覆盖缓存。浏览器清理站点数据、隐私模式限制或浏览器自身存储回收不属于应用可保证的长期备份。

这些数据是导入缓存格式，`VoxelResult` 仍是转换快照；不作为未来完整编辑项目格式、撤销历史或跨设备同步协议。

## 展开按钮与键盘导航

`renderer/orbit-pinch.ts` 单独处理轨道视图的触摸板缩放：捕获 Ctrl+wheel/WebKit gesture 并避免重复处理，按对数距离累计目标，在 Viewer 现有循环中以帧时间平滑接近，不改变 FOV。普通滚轮仍交给 OrbitControls，避免其额外 10 倍捏合增量叠加页面 3 倍速度。减少动态效果时直接更新距离；控件开始其他操作、失焦、隐藏、选点、适应与恢复清空目标，卸载解除监听。

`ToolButton` 的可选 `expanded` 属性与命名 `icon` 插槽统一展开反馈：展开为黑底、金色向上箭头，收起恢复传入的图标；未传 `expanded` 的普通按钮不改变语义和样式。工具栏负责具体面板状态，并提供对应的 `aria-controls`。

`renderer/keyboard-navigation.ts` 由 Viewer 创建、逐帧更新和释放，复用渲染循环与预分配向量。WASD 按摄像机方位在水平 XZ 平面移动，不受俯仰角影响高度；从水平右向量推导前向量，俯视/仰视时也保持稳定。↑/↓ 单独沿世界 Y 轴升降。摄像机和 OrbitControls 的 target 同步位移，不改变鼠标轨道控制与缩放。

视口组件以 `navigationEnabled` 接收“已有模型且不忙”的状态，传递给 Viewer；只有画布获得焦点时读取移动键，点击画布会获取焦点。处理任务、焦点离开画布、窗口失焦及页面可见性变化均清除按键状态；修饰键组合与输入法组合输入不触发移动。水平组合方向归一化，水平/垂直速度独立，步行及轨道默认 8/8，飞行默认 14/14 blocks/s；模式变化选择对应配置，不重置另一组。步行/飞行切换清除疾跑状态但保留升降按键，避免 ↑ 键进入飞行后失效。每帧时间上限 50 ms，防止恢复显示时跳跃。

350 ms 内双击 W，第二次按住时使用基础水平速度的 1.3 倍；松开 W、按 S、失焦、任务禁用或切换导航模式时结束。共享输入层使轨道平移、步行与飞行均可使用该操作，只加成有前进分量的水平位移，不改变基础速度设置、垂直速度或跳跃重力。此处是本工具的疾跑规则，不实现饥饿、耐力或完整游戏运动系统。

`TransientBar.vue` 是可复用的插槽容器，提供 `refreshKey`、`duration`（默认 5000 ms）、`enabled` 与 show/hide 接口；触发后从底部滑入，内容更新或操作重新计时，超时滑出并变为 inert。容器用 ResizeObserver 通知高度，App 留出状态提示间距，内容折行或第一人称提示出现时不重叠；卸载释放观察器与计时器。`NavigationBar.vue` 同时显示步行和飞行两组，管理共享方向按钮及各组数字草稿，用户无需在锁定鼠标后操作。滑条 1–50，数字接收任意正有限数，不加业务上限，超出滑条范围时仅把滑条显示夹到端点；无效草稿失焦时恢复当前值。Viewer 的移动活动通知最多每 100 ms 一次，不让 Vue 跟随逐帧坐标变化。

所有运行时 `input[type=range]` 共用 `style.css` 的样式：24 px 高的操作区域、2 px 直线轨道与 12×12 px 方形滑块，无圆角，沿用黑金主题；提供 WebKit 与 Gecko 伪元素规则。切片和速度控件只定义布局与尺寸，不各自覆盖轨道或滑块。原始 ref 快照保持不变。

## 第一人称、碰撞与 FOV

入口先进入落点选择并显示有背景的指引，冻结轨道惯性和键盘平移；用户再点击建筑或可见网格内的 Y=0 地面。仅此时进行一次射线拾取并请求鼠标锁定，空白处不使用隐藏无限平面、不复用旧落点；Esc 或再次点击入口取消选择。鼠标锁定失败保留原相机和轨道视图，按用户确认不提供拖动转向降级。成功后角色脚放在选择处，视点高 1.62 格；若身体与建筑重叠，向上腾出站立空间。选点状态与锁定状态不持久化，刷新回到轨道模式并恢复相机位置及朝向。

`renderer/first-person.ts` 组合 Three.js 自带 PointerLockControls 与核心 `walking`。角色包围盒宽 0.6、高 1.8 格；步行使用当前 `VoxelResult` 的完整方块、半砖、楼梯和展示架实际盒形，逐轴扫描移动路径附近格子并限制位移，避免按速度步进导致穿墙，也不分配整世界碰撞副本。Space 地面跳跃（重力 24 格/秒²，目标跳高 1.25 格）；300 ms 内双击 Space 切换飞行，↑/↓ 直接进入飞行升降，飞行时 Space 也可上升。飞行忽略侧面和向上阻挡，下降碰到建筑顶面或 Y=0 地面时落地退出；双击 Space 也可退出飞行，身体处于方块中时先腾出步行空间。

第一人称只改投影的滚轮 FOV 范围为 20°–100°，向上放大、向下缩小；Shift 使用五分之一的调整速率，并统一像素/行/页滚轮单位。`first-person-fov.ts` 独立保存当前站点的全局浏览器偏好，默认 40°；调整时以 250 ms 节流写入 localStorage，退出/失焦/隐藏/卸载刷新待写值，进入时读取记住的值。新模型或历史恢复不覆盖该偏好，不为每条历史保存 FOV。非法或不可用存储回退到会话值，不阻断导航。退出仍恢复进入前的轨道 FOV，不改变轨道模式滚轮缩放。Pointer Lock、滚轮、全局焦点、选择事件均由 Viewer/第一人称控制器释放；处理任务、窗口失焦和隐藏会退出锁定。未引入物理引擎或新的依赖；该功能不包含自动跨台阶或完整 Minecraft 运动复刻。

触摸板缩放在第一人称控制器内同时接收 `ctrlKey` 为真的 `wheel`（Chromium/Firefox）和 WebKit 的 `gesturestart/change/end`。原先过滤 Ctrl 的逻辑会漏掉前者，参见 [MDN wheel 事件说明](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)；WebKit `scale` 是相对手势起点的倍率，参见 [Apple GestureEvent.scale](https://developer.apple.com/documentation/webkitjs/gestureevent/1632653-scale)。手势按倍率调整半视角正切值，张开放大、捏合缩小，沿用范围、Shift 精细调整与全局保存；普通滚轮和双指滚动保持原角度增量。原生 gesture 进行中忽略重复 wheel 缩放，退出清空手势状态，卸载移除全部监听。只在第一人称阻止默认页面缩放，轨道视角不拦截；浏览器将 Ctrl+滚轮与捏合放在同一路径，因此第一人称内两者均调整 FOV。

## 完整方块编辑与建筑记录

`core/building.ts` 的 `BuildingDocument` v2 保存只读 `VoxelResult` 基底、调色板、16³ 手工覆盖分块、墙节点/预设、派生分块缓存、世界边界和操作历史。覆盖形状 0 表示未覆盖，255 为明确删除；查询时依次使用手工覆盖、原基底、墙体缓存，255 返回空气。这样笔刷可以删除导入方块而不改写转换快照，已有基底仍在新增形状前优先保留。所有层都保持稳定坐标，允许负 X/Z，禁止 Y<0；空白建筑不伪造 GLB。旧 v1 增量与逐格历史在读取时迁移，不删除旧数据。旧 v2 的固定三项墙预设连同历史快照迁移为结构列表；保留预设 ID、引用、厚度和开关，数据库及文档版本仍为 v2。

`block-world.ts` 提供统一的 bounds/shapeAt/materialAt 查询，转换结果由 VoxelWorld 适配。`building-pick.ts` 沿射线与 SHAPE_BOXES 精确求交；拾取、切片、碰撞与导出共用分层语义。`BuildingWorld.topAt` 为地形笔刷查询每列最高实体表面，通过分块索引跳过基底以上空段。导出在 Worker 中合成基底、墙体和手工覆盖，转换为临时 VoxelResult，删除标记编码为空气；Schematic v2 只包含最终方块。

`core/building-commands.ts` 负责批量笔刷、墙节点/预设与撤销重做命令。一次形状放置、碎裂落笔或节点/预设自动提交记录一步，保存覆盖前后值或节点参数；新端点对应一次墙节点提交。单块/平滑的每次按下生成独立 stroke ID，增量提交时合并相邻同 ID 的历史项，保留每格首次 before 与末次 after；主线程使用同一合并逻辑，仍只传本次变化而不反复回传整笔记录。每笔最多 262,144 个不同格子，历史游标及合并记录随每次增量原子保存，刷新可整体撤销。默认容量 50，正安全整数且不预分配；缩容优先保留最近撤销及紧接的重做，不改动当前建筑。主线程 `accept` 接收同一操作与变更分块，不复制整座建筑或每次往返全部历史。

`core/walls.ts` 以路径、二次贝塞尔控制点和结构列表生成墙体。预设最多 64 项表单，每项包含 ID、种类、图案、独立厚度/空心、启用、间隔及偏移；可包含多个墙面、驻点和支撑。`wall-layout.ts` 将驻点作为独立列插入完整墙面循环后，不占用墙面图案的列：多墙面宽度的最小公倍数作为完整循环，驻点间隔/偏移以该循环计数，新驻点默认间隔 1，同轮多个驻点按表单顺序追加。支撑间隔/偏移仍以实际路径格数计数，其图案列以触发位置居中，偶数列向前多一列，法线方向厚度不变。路径先密集采样距离/切线，再将连续落入同一体素格的采样合并，采用最接近格心的一次、在整数格心生成；这样反向路径的半格取整不会让不同图案列覆盖同一格并复制末列。原始采样量仍单独受预算保护。

支撑在开放/未知轮廓生成两侧，在可识别闭合轮廓应用节点的内外开关。内外识别使用采样后的 XZ 轮廓、朝向与自交检查，退化/过复杂时返回未知。预设由同建筑节点共享引用，副本 ID 独立；改变引用或预设后重算生成缓存。Worker 按生成版本、节点及预设签名复用未修改墙体缓存，比较最终分块，只提交变化分块与邻块的网格。手工覆盖优先于节点，所以地形笔刷的明确修改在节点更新后仍保留。当前派生缓存标记为 `wallLayoutVersion: 3`；缺失或旧值 2 在后台初始化后串行 refresh 并原子保存，不增加历史步骤。旧参数数值保留，驻点间隔使用已确认的循环单位；数据库和 BuildingDocument 版本仍为 v2。

`core/surface-stroke.ts` 处理单块连续绘制。StrokeSurface 只记本笔新增坐标并读穿当前世界，排除自身新增实体，保留初始 bounds，不复制建筑。Worker 保存当前 stroke 的上一射线、落点和排除集合，对稀疏输入插值拾取真实形状，再按整格遍历补齐相邻落点；只接受地面或紧邻原表面的空格，避免曲面间的悬空连线。结束释放 stroke，失败标记阻止排队尾段重新使用已更新表面。每批最多 256 条射线、8192 次采样，整笔不同格数沿用 262,144 上限；并非任意连续网格的曲面重建。

`core/wall-guides.ts` 只计算水平基准、实际转角及整数格约束。首段以 +X 为基准，后续使用上一段方向（曲线末端切线，纯竖直段沿用前一有效方向）；Alt 按相对基准吸附 45° 倍数，Shift 独立锁高，可组合。坐标取整后反馈实际角度，不伪造严格角度值。`renderer/wall-guide.ts` 负责现有节点的屏幕投影、70px 半径内的最近吸附、整格方块线框与有内边距的角度标签；不选控制点、不自动插入路径节点、不创建持久连接关系。节点坐标去重，投影在节点/草稿或相机/视口变化时更新，普通悬停复用缓存；屏幕边缘的候选也按该半径裁剪，约束不兼容的候选不吸附。BuildingView 的预览与点击共用相同落点函数，连接只复制坐标，原墙线不受新墙修改影响，沿用原节点命令/撤销/保存和预算。

`useBuilding.attachViewer` 在恢复/重建视口时通过 Viewer.setWallNodes 显式传入权威节点数组，每次 Worker 增量接收后同步；拾取不再依赖 BuildingWorld 的运行时类身份临时提取节点，也不要求预先选择某条墙线。换世界清空旧数组/投影，收到新数组后使候选缓存失效，撤销、重做、删除与恢复使用同一同步路径。辅助路径使用 Three.js 自带 Line2/LineMaterial，以屏幕单位绘制 5px 连线，onBeforeRender 按当前视口更新 resolution；按容量增长并复用线段缓冲区，变化时只更新辅助路径，不重建建筑。连接与起点标记均为一格、世界轴对齐的线框，不随相机转成圆环。

WallGuide 由 BuildingView 持有，标记及提示不进入响应式状态、建筑文档或 Worker。离开视口、Space 旋转、任务阻塞、切换笔刷/模式时隐藏，失焦清空修饰键；切换世界重置候选缓存，卸载释放 DOM 标签和标记几何/材质。标签无指针事件，位置限制在视口内，预留文字边距；不创建第二套渲染循环。

`core/terrain-brushes.ts` 平滑最高表面的高斯加权高度，沿圆形边缘减弱并保留原列材质，不声称体积守恒或洞穴平滑。龟裂计算二维 Voronoi 边界距离并轻微扭曲；宽度采用实际边界距离，非 F2−F1 的近似宽度。世界坐标/种子保持连续，完整边缘高度用于估计裂缝底部，缺少边缘则跳过，不持续向下钻挖。

`useBuilding.ts` 持有浅引用世界、选择状态、常驻 Worker 与串行自动保存。命令串行排队，计算期间阻止新笔和建筑切换，但接收当前单块笔画的射线及松开尾段，避免后台繁忙丢失快速输入；表单仍允许继续修改。失败保留当前场景，命令成功后才接收结果，下载等待已经排队的命令；节点保存回执仅在选择尚未切换时更新选中节点，避免旧确认抢回选择。useAutoDraft 校验网格/节点草稿，以 180ms 合并有效输入；收到较早的后台确认时保留更新的本地草稿，外部撤销/删除则采用权威状态，避免重新创建已删节点。切换预设/节点或收起菜单前提交有效草稿，销毁/切换建筑时取消未提交计时器；KeepAlive 最多缓存当前建筑一份面板。纯 JSON 表单在提交前序列化为普通数据，防止嵌套 Vue Proxy 进入 Worker。

全部笔刷共用同一紧凑选项尺寸和按视口高度约束的固定面板高度，切换类型不改变外框/选项布局。墙体设置使用紧凑的类型/序号卡片，子结构名称字段仍保留在历史数据中以兼容旧记录，但不提供编辑入口。WallPatternEditor 将已有二维图案与一圈临时扩展格分开显示，悬停/焦点仅更新预览；左键点击后扩展最多一行/一列并复制原图案，新增未填格为 null，左/下扩展按新索引平移原格。右键清为空气后调用纯函数 `trimWallPattern`，裁去四周全空边缘，保留内部空气和最小 1×1；点击既有空白边缘也可触发裁剪，扩展区右键仅取消预览。读取旧图案不自动裁剪，左键扩展也不立即裁去新留白。达到 64 的轴不再提供外扩格。只提交实际图案数据，裁剪与图案修改一同进入自动应用/撤销/保存；临时格/焦点不进入 Worker、操作历史或缓存。

`BuildingView` 持有修改分块 Mesh、5×5 网格、形状预览、路径和起点标记；预览中单击阈值 5px，首次仅进入。编辑时禁用默认旋转/平移，按住 Space 才开放轨道拖动，滚轮仍可缩放；单块/平滑捕获左键指针。单块记录普通射线数据，以最多 128 条一批送后台补格，等待期间仍接收移动及最终松开；预览同样排除已确认的本笔新增格。平滑保留每 120ms 空闲采样。松开、失焦、隐藏、取消或快捷键操作结束整笔，切换世界/卸载丢弃未提交旧场景尾段并释放资源。Space 拖动不落笔，第一人称规则不变。墙线 Shift 锁定端点高度，Ctrl 选端点后补控制点；点击起点标记闭合。Esc 优先结束选点，无选点时返回预览；第一人称前退出交互。所有笔刷优先命中真实表面，无命中时交 Y=0 地面；不保留显式落点 Y 设置。辅助几何不作为世界数据或普通建筑拾取对象。Viewer 的参考网格使用一格间距、整数中心和偶数跨度，在尺寸/中心跨分桶时才重建，与方块边界对齐。静态基底不重复复制；`BaseChunkMask` 用小份 GPU 分块遮罩隐藏已由局部网格替换的原表面，未修改基底继续复用静态网格。局部网格复用真实形状、变体纹理与降级颜色。遮罩、预览与分块 GPU 资源在切换/卸载时释放。

`adapters/editor/` 使用每建筑一个常驻 Worker，初始化克隆一次基底，后续接收 command，返回操作增量、变化缓存及带 revision 的分块网格。主线程核对会话代号并过滤旧分块；不改动原 convert/remesh/export 协议。预览仍限制 125 万三角面；失败保留原可用局部预览和建筑数据/导出。新增操作限制单次形状包围体积/地形修改最多 262,144 格，模板行列最多 64，墙线 4096 点，避免单次参数造成无界分配。墙体还有采样/生成工作量保护。总体沿用 3200 万格及单边 65535 限制；没有性能基准或无卡顿承诺。

IndexedDB 数据库仍为 v2，保留旧导入和建筑条目；BuildingDocument 自身版本升到 2。buildingChunks 的原 key 继续表示手工层，`generated|` 前缀保存派生缓存，无需删除/升级现有 store。kind=building 区分建筑；缺失 kind 的旧记录仍为导入。首次有效编辑（包含新建预设）另存独立建筑，基底体素/静态表面只在创建时用新 ID 保存，之后只写两层脏分块。原导入删除不影响建筑，空白入口直接建档，空建筑禁止下载。

建筑元数据、两层脏分块、节点/预设、操作历史/游标、容量及活动条目在同一事务保存；快照只复制脏分块，参数/操作按提交后不可变处理。读取校验版本、类型数组、材质、模板、节点、分块计数和边界。保存失败保留内存及旧快照，恢复脏标记；切换先等待保存，后台命令未完成时拒绝切换并提示，允许删除旧记录腾空间。删除当前条目后脱离保存。相机仍节流小份元数据；页面关闭不保证尚未完成的 Worker 命令或浏览器被强杀时的数据提交。

## 性能与兼容约束

保持输出最多 3200 万格、预览最多 125 万三角面、掉落最多 100 万长方体实例；预算值的实现分别在 `geometry`、`surface` 和 `falling-data`。超预览预算仍可切片和导出，超动画预算或减少动态效果时显示静态结果；贴图失败保留代表色，无 WebGL 时仍可转换、切片与下载。

GLB 转换保留算法、采样、贴图、灯光与持续渲染循环。读取/场景解析仍在主线程且不可取消；转换模式换材质仍重新合并整张预览。编辑局部替换受影响的基底区域，不全量重建基底；遮罩保留原基底三角面作为预算基数，预算统计偏保守。未新增 LOD、性能指标采集或帧率承诺。

后续独立拆除工具、半砖/楼梯放置和可交换项目格式仍随具体功能设计；`VoxelResult` 只是转换快照，BuildingDocument 是内部本地状态，不作为对外通用项目格式。渲染 Mesh 不能成为唯一建筑数据。

## 文档与验证

指导入口为根目录 `AGENTS.md`；`LOCAL_HANDOFF.md` 仅保存当前摘要；根目录 `CHANGELOG.md` 保存倒序历史；README 保存使用与素材维护说明。每次实际改动同步最新记录，架构变化更新本文件，避免另建同用途交接文档。

`npm run typecheck` 使用 `vue-tsc --noEmit` 覆盖 `.ts`、SFC 模板、测试、脚本和 Vite 配置；`npm run check` 保留完整测试、类型检查与生产构建。日常按用户约定只做必要静态与桌面视觉检查，部署前执行聚合检查。Axiom 导入和复杂模型验收需单独记录。
