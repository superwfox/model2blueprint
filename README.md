# GLB → SCHEM

在浏览器本地把静态建筑 GLB 转为 Minecraft Java 26.3 的 Sponge Schematic v2。模型无需上传，支持完整方块、上下半砖、楼梯和四向展示架。

## 项目与开发入口

技术栈为 Vue 3、TypeScript、Vite 和 Three.js，源码按计算核心、浏览器适配层、Vue 应用层组织。已支持浏览器本地历史、完整方块笔刷、可编辑墙节点、地表平滑与龟裂、独立建筑记录与撤销重做；单格拆除工具、半砖/楼梯放置、可交换编辑项目格式与多人协作尚未实现。

开始开发先读 [AGENTS.md](AGENTS.md)、[当前状态](docs/LOCAL_HANDOFF.md)、[架构约束](docs/ARCHITECTURE.md) 和 [Changelog 最新记录](CHANGELOG.md)。每轮实际改动同步摘要与 Changelog，架构变化同步架构说明；历史按需读取，避免把旧交接和旧构建当作当前验证。

## 使用

1. 从 Blender 导出 GLB 2.0：选择需要的建筑部件，嵌入资源，关闭 Draco 几何压缩。
2. 将文件拖入窗棂细框或点击「选择 GLB 文件」即可自动转换。麦金色角花在处理期间顺序起伏，随进度加快，接近完成后恢复；启用减少动态效果时不播放动画。加载框淡出后，可见方块从上方独立掉落，整体由低处逐步搭起。
3. 工具栏可修改最长水平边（默认 256），其余尺寸等比计算，底部归零；材质按钮可分别选择每种材质的完整方块、半砖、楼梯和展示架，支持中文名或方块 ID 搜索。
4. 转换成功后，顶部品牌栏隐藏，工具栏上移并收紧高度与长度，为三维预览腾出空间；更新材质或导出期间保持该布局。工具栏可切换原模与方块结果；点击材质或切片按钮时，同一个顶部容器伸展开，内容在容器内显示，按钮变为黑底、金色向上箭头，收起后恢复。点击三维视口获得焦点后，WASD 按当前朝向在水平 XZ 平面移动，不随俯仰改变高度；↑/↓ 单独沿 Y 轴升降。点击输入控件或窗口失焦后停止移动。普通缩放速度提高到 3 倍，按住 Shift 恢复原有的精细速度。切片以四分之一格高度检查，按展示架的真实轮廓绘制。
5. 下载 `.schem`，在 Axiom 的 **File → Import Schematic** 中导入。
6. 下载按钮右侧的时钟打开「本地历史」。每次成功导入保存一条记录，后续尺寸重转和材质修改更新该条；可恢复到视图或删除。刷新自动恢复上次打开的记录，包括方块结果、原模、尺寸、材质映射、预览模式、相机位置和移动速度；恢复方块预览无需重新导入或转换。

### 放置方块

首次左键点击建筑只进入编辑模式并切换顶部栏，之后使用所选笔刷单击或选点；单块、平滑可按住左键持续操作，编辑中按住 Space 再拖动旋转视角，预览模式仍直接拖动旋转。光标处显示贴合建筑表面或地面的 5×5 网格及预览；蓝色预览表示该单块或形状落点无效。编辑栏移除「切片」「退出编辑」，保留导入预览的切片入口。仅在轨道视角编辑：选点期间 Esc 结束墙线或取消未完成形状，再按 Esc 返回预览；点击建筑或「继续编辑」重新进入。进入第一人称会先退出编辑交互。

主页的「从空白模板开始」直接创建空白建筑，只有 Y=0 参考地面，没有实体底板。参考网格为一格间距，与整数坐标的方块边界对齐。默认方块为石头，顶部可搜索现有完整方块目录并更换材质；支持向四周及上方扩展，不在 Y=0 以下放置。沿用单边 65535、包围体积 3200 万格和预览三角面预算，新增分块也有分配预算。空建筑不能下载。

单块长按始终跟随本笔开始前已有的表面，忽略本笔新放的方块，停留或往返不会不断叠高；松开再落笔才使用更新后的表面。快速或不匀速拖动会补齐沿途格子，曲面和台阶按已有方块表面绘制，不增加模式选项。

顶部提供撤销与重做，快捷键为 Ctrl/Cmd+Z、Ctrl+Y、Ctrl/Cmd+Shift+Z，输入框内保留原输入行为。每个建筑默认保存 50 步，可输入正整数调整；缩小容量不会改变当前方块，撤销后新操作会丢弃旧重做分支。单块或平滑的一次按下到松开合并为一步（刷新后仍可整体撤销/重做）；其他批量笔刷、节点或预设修改算一步，墙线每次确认新端点算一步。无效操作和没有变化的落笔不占记录。形状和墙线保留点击选点，不支持半砖/楼梯放置。

导入建筑首次有效编辑（包括建立墙体预设）会另存建筑记录，原导入记录保留；空白入口直接保存空建筑。方块修改、墙节点/预设、选材、记录容量和撤销/重做历史自动保存在当前浏览器，刷新或从本地历史恢复后可继续编辑。建筑记录独立保存基底，删除原导入不会连带删除建筑；保存失败保留当前场景与旧快照，可下载或删除旧历史释放空间后重试。切换建筑前等待保存，后台笔刷尚未结束时保留当前场景并提示。下载仍为 `.schem`，只含最终方块，不包含墙节点、预设或撤销记录。

### 笔刷与墙体预设

顶部「笔刷」合并选择与设置，展开后用横排方块卡片选择单块、墙壁、长方体、球体、平滑和碎裂，下方显示对应设置。所有笔刷共用紧凑选项和稳定的公共位置，配置按实际内容占用高度；复杂配置最多 360px 并随视口进一步限高，在内部滚动，切换笔刷返回配置顶部。展开、收起及配置变化均平顺调整高度，不再为单块等简单配置预留大块空白。连续放置只更新数量/保存状态，不再逐批将整栏按钮变灰，下载会等待已排队操作。新增几何使用完整方块，默认填入空格并保留已有方块；平滑和碎裂会改动现有表面。长方体/球体默认实心，可切换空心（壳厚 1 格）：固定长方体先设置 X/Y/Z 尺寸，固定球体设置半径，再单击放置；灵活长方体选择两角，灵活球体选择球心与半径点。落点自动跟随命中表面，没有表面时使用 Y=0 地面，不再提供单独的落点 Y 设置。球体不能跨到 Y=0 以下。

墙壁连续点击延伸同一条路径，允许高度差。靠近已有墙线的端点或中间节点时，在屏幕 70px 半径内吸附最近兼容节点，显示与该格边界对齐的金色方块线框；刷新或从历史恢复后，选择墙壁笔刷即可连接旧节点，无须先在面板选择墙线。点击即可使用该节点的坐标作为起点或下一点；各墙线仍独立编辑，不建立自动联动的连接关系，也不在路径任意位置插入节点。起点同样显示方块线框，辅助路径为屏幕宽度 5px，至少三点后点击起点闭合；Esc 结束当前墙线。节点面板可重新选点、修改 XYZ 与曲线控制点、更换预设、定位或删除整面墙，删除可撤销。

选下一点时，预览旁显示水平角度：首段相对世界 +X，之后为相对上一段的有符号转角，曲线使用末端切线方向。按住 **Alt** 吸附到相对基准的 45° 整数倍；**Shift** 单独锁定上一端点高度，可与 Alt 同用。**Ctrl** 保留曲线操作，先选端点再点击贝塞尔控制点。落点仍是整数格，任意斜向基准取整后可能有角度误差，提示显示实际角度。约束开启时只吸附满足约束的已有节点，预览与最终点击使用同一坐标。

墙体设置左侧为预设列表，右侧横排结构表单。可追加、删除、启停多组「循环墙面」「驻点墩」「两侧支撑」，子结构以类型和序号区分，不设名称输入。每项独立设置图案、厚度、空心与偏移；驻点和支撑还可设置间隔。多个驻点可通过偏移交错。每个预设最多 64 项结构，模板用「沿路径的列 × 高度的行」绘制；方块图是配置重心，默认展开即可看到。鼠标靠近边缘会显示一圈扩展格和当前方块预览，左键绘制并按需扩展行列，右键设为空气并裁去四周整行/整列的空白边缘；内部空气保留，全部清空后保留 1×1 空气格。扩展区右键只取消预览，不扩展；旧图案仅在主动清除时裁边，不在读取时改变。行列不再用数字框设置，上方对应墙顶。墙面与驻点的厚度居中展开，支撑厚度是向每侧延伸的格数；空心保留厚度两侧、顶底及端部。

驻点插入完整的墙面循环之后：3 列墙面加 1 列驻点构成 4 列周期。新驻点间隔默认 1，设为 2 则每 6 列墙面后插入；多个驻点在满足间隔时按表单顺序追加。驻点偏移以墙面循环序号计算；多个墙面取共同完整循环。支撑的间隔和偏移仍以沿路径的格数计算，图案沿路径以触发位置居中，偶数列多出的一列朝路径前进方向；向墙两侧延伸的厚度不变。旧记录保留已设数值，驻点间隔按新循环单位解释；恢复时自动重建旧墙体缓存，不占撤销步数。

开放墙线也会生成两侧支撑；只有闭合、非退化且未识别为自交的 XZ 轮廓才显示内外开关，无法识别时隐藏开关并生成两侧。预设、结构和节点的有效修改稍作合并后自动应用，没有手动保存/应用按钮；无效参数保留上次有效建筑并提示。共享预设更新所有引用节点，「复制为副本」生成独立预设，墙节点改为引用副本后可单独修改。预设库随建筑保存；旧预设及其撤销快照会迁移为结构列表。

平滑按周围地表高度削峰填谷，半径 1–64、强度 5%–100%，边缘渐弱，补入方块尽量沿用该列原表层材质。碎裂使用按世界坐标采样的二维 Voronoi 边界与轻微扭曲，默认半径 8、裂块大小 8、宽 1、深 3、种子 1；可调范围见面板。以未开裂边缘估计沟深，保持相邻落笔的裂纹连续；没有可识别完整边缘时跳过该列。平滑支持长按持续操作且整笔撤销，碎裂仍为一次单击一步。

性能保护：单次长方体/球体包围区域最多 262,144 格；地形笔刷单次修改、整笔长按的不同修改格数也有相同上限；模板各行列 1–64，单条墙线最多 4096 点，超大墙体生成会拒绝并保留原内容。总体仍受 3200 万格、单边 65535 与预览预算约束。墙体是可编辑节点；其他笔刷生成直接方块变更，之后修改墙预设不会覆盖已用地形笔刷明确修改的格子。

### 视角与本地缓存

移动时底部滑出临时栏，同时显示步行和飞行两组速度，进入第一人称前可一起调整；按钮切换水平/垂直方向。步行及轨道平移默认 8 blocks/s，飞行水平/垂直默认 14 blocks/s；滑条范围 1–50，旁边数字允许任意正有限数（可超过 50）。步行组垂直设置用于轨道升降，第一人称步行高度仍由跳跃与重力控制。两组设置分别随导入历史保存，旧记录已保存的共享速度保留为步行设置，飞行使用新默认值。新导入使用 8/14 默认值。操作或内容刷新后重新计时，5 秒无更新便滑出视窗。

350 ms 内双击 W 并按住第二次可疾跑，水平速度为设定值的 1.3 倍（例如 10 → 13 blocks/s），升降速度不变。松开 W、按 S 或失焦后恢复基础速度。

轨道视图的触摸板捏合/张开使用连续倍率和平滑距离更新，Shift 精细调整；普通滚轮保留现有速度，减少动态效果时直接更新距离。

点击临时栏「第一人称」后，按提示点击建筑或可见地面选择落点；空白处继续选择，Esc 取消。进入后锁定鼠标转向，WASD 水平移动，Space 跳跃，双击 Space 切换飞行，↑/↓ 进入飞行并升降，飞行时 Space 也可上升。步行有方块形状碰撞；飞行可穿墙和向上穿楼板，下降接触建筑顶面或基准地面时落地退出。滚轮或触摸板缩放手势调整 FOV（20°–100°），双指张开放大、捏合缩小，Shift 精细调整；第一人称内 Ctrl+滚轮也调整 FOV，手势不会缩放整个页面。第一人称 FOV 按当前浏览器/站点全局记忆，退出再进入、刷新或换模型均沿用上次值。Esc 返回轨道视图并恢复进入前的轨道 FOV。刷新恢复相机与速度，不会自动锁定鼠标。浏览器不支持或拒绝锁定时保留轨道视图；请使用支持 Pointer Lock 的普通浏览器。

记录存于当前浏览器的本地 IndexedDB，不会上传。应用不自动清理记录；空间不足或存储受限时保留旧记录并提示本次未缓存。删除历史会保留当前画面，已删除视图不会因后续操作自动重新建档；重新导入可再次保存。清理浏览器站点数据会清除记录，隐私模式或浏览器存储回收也可能影响保留；重要建筑仍应下载 `.schem`。导入记录是转换缓存，建筑记录另含编辑操作历史；面板搜索与切片位置不持久化。

三维方块预览和材质面板使用内置的 Pixel Perfection Legacy 方块贴图，原模型保留 GLB 自带材质；切片采用代表色以便检查轮廓。以 GLB 的 Y 轴为上方，保持场景方向，粘贴原点为输出区域最小角。

## 本地开发与构建

需要 Node.js 22.18+（项目固定为 24.12.0）。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

`npm run build` 自动执行核心测试、Vue/TypeScript 检查及生产构建，生成 `dist/`；`npm run check` 是同一聚合流程。`npm run typecheck` 使用 `vue-tsc --noEmit`，也检查 Vue 模板；`npm test` 可单独运行。日常按协作约定默认不执行测试套件或生产构建，Web 改动做必要桌面视觉检查；部署前必须完整验证。

## Cloudflare Pages

**直接上传**：将交付的 `glb2schem-pages.zip` 上传到 Pages 的 Direct Upload 项目。压缩包根目录即为 `index.html`，无需再次构建。

**连接 Git 仓库**：将本项目设为根目录；框架选择 None，构建命令 `npm run build`，输出目录 `dist`，Node 版本使用 24.12.0。

没有服务端、Pages Functions、远程数据库、模型上传或第三方 CDN；导入历史仅使用浏览器本地 IndexedDB。`public/_headers` 随构建发布。部署前还应完成桌面视觉检查及目标 Axiom 中的实际导入核对。

## 几何处理与边界

- 恢复因法线、UV 和材质分片拆开的逻辑拓扑；检查封闭性，将封闭连通部件作为独立实体。
- 在空间分区索引上进行竖直扫描。每个部件分别求内部区间，再合并区间，避免相交实体发生 XOR 抵消。
- 每格以 36 条带面积权重的竖直射线积分八个半格子区，以及四向展示架的真实覆盖量。采样分区与半格、展示架边界对齐，不分配全世界的细网格；按体积误差选择空气、半砖、完整方块、楼梯或展示架。恰好 50% 时用对应子区中心采样消除歧义。封闭部件分别求区间后取并集，相交实体不会抵消。
- 楼梯包含四种朝向、正放与倒置，以及直线、内拐角、外拐角，共 40 种显式状态。拟合采用 Minecraft 的实际半格几何；三维预览、掉落动画、切片和导出使用同一形状。
- 展示架按原版模型的背板（厚 3/16 格）、上下凸沿（各高 1/4 格，最大深度 5/16 格）拟合，支持北、东、南、西四向。预览裁去相接内部面并合并共面矩形；动画的三部分共用一个方块落点。导出为空架、未充能、未连锁、未含水状态，不写入存放物品。
- 圆台辐条和裂缝按原几何采样，不进行平滑、填缝或全局膨胀；楼梯为斜线、圆弧和破损边缘提供更多贴合形状。更细的采样无法突破 Minecraft 方块本身的形状限制。
- 几何先确定，再按覆盖材质赋予方块。替换材质映射时保持几何不变。同格上下材质冲突时选总覆盖量较大的材质。
- 放置坐标精度为 1 格；半砖和楼梯内部可表达半格边界，展示架提供特定的更薄竖向形状，不能单独放置任意厚度的薄片。更细的缝和薄片仍可能丢失；模型必须有实际厚度。
- 嵌套且互不连接的封闭壳按多个实体取并集；密闭空腔应在 Blender 中建成具有连接拓扑的实体。透明贴图、动画、骨骼、Draco、Meshopt 和 KTX2 不在首版输入范围内。
- 最多 3200 万个输出方块位置。三维预览超过 125 万个可见三角面时保留完整转换数据，改用切片或导入游戏检查；导出不受预览限制影响。
- 预览在后台线程合并相邻表面，取消时终止线程。大模型的读取和 GLB 场景解析发生在主线程，读取阶段不显示取消按钮。
- 掉落动画使用独立方块及真实的竖直位移，完整方块、半砖和楼梯保留各自的尺寸和落点。楼梯由同一个方块锚点控制，组成部分同时运动。动画结束后释放实例，切回合并表面；封闭内部的完整方块、半砖、楼梯和展示架不参与动画，导出数据保持完整。动画从加载框淡出后的首个可见帧开始计时，慢帧和后台等待不会直接跳过掉落过程。超过 100 万个动画长方体实例或启用减少动态效果时直接显示模型。

## 材质库

当前目录包含 379 种完整方块材质、101 种半砖、97 种楼梯和 13 种展示架，共 590 个原版方块 ID。收录建筑、彩色和天然材料，排除容器、工作站、红石机关、生成器等功能方块；按用户要求，空展示架作为明确例外加入。栅栏、墙、玻璃板、花草、地毯等其他形状不参与拟合。

目录从本地原版 26.3 游戏文件提取，包含创造栏分类、真实模型、中文名和按贴图 alpha / 模型表面面积估算的代表色。铜的氧化与涂蜡系列完整展开；羊毛和混凝土各包含 16 色完整方块、半砖与楼梯。全部候选状态与对应版本的方块状态报告核对，避免根据名字臆造不存在的楼梯或半砖。

有同材质变体时优先配套；例如矿石、玻璃、树叶没有原生半砖或楼梯时，自动配合法的近色形状。四种形状可以分别手动修改，三维预览、面板缩略图与导出使用实际选中的方块；切片使用对应代表色。更换完整方块会更新未手动指定的搭配，保留已手动指定的半砖、楼梯和展示架；搜索也会保留当前选择。展示架只有游戏实际提供的木质版本，没有虚构的石质或彩色展示架。

树叶写出 `persistent=true`，避免自然掉叶。自动匹配不选择玻璃、冰及会失活的活珊瑚等易改变外观的选项，手动列表仍可选；铜色完全相同时优先涂蜡版本。模型仍需满足静态、封闭的 GLB 输入要求。

目录保存于 `src/data/block-catalog.json`，运行和构建无需本地 Minecraft。维护者可用 Python + Pillow 重新生成（仅此离线工具需要它们，不是网页生产依赖）：

```sh
python scripts/generate-catalog.py "路径/26.3.jar"
```

脚本只读取游戏文件，不启动游戏、不修改安装目录，也不把原版贴图或游戏 JAR 放进发布包。`scripts/data/catalog-audit.json` 记录分类来源和排除原因；版本固定为 26.3 / DataVersion 5023。

### 预览贴图与署名

网页内置 [Pixel Perfection Legacy 26.3-97.1](https://modrinth.com/resourcepack/pixel-perfection-legacy) 的必要方块贴图，原作者为 Hugh “XSSheep” Rutland，由 Nova_Wostra 与贡献者续作，贴图按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 分发。署名、来源及改动说明随静态文件保存在 `public/textures/`；材质面板也提供作者页面入口。未打包 Minecraft 原版贴图。

590 个候选方块共用一张约 138 KB 的本地图集，按面方向选择贴图，合并大面仍按每格重复纹理；掉落实例与静态表面使用同一贴图。图集取动画首帧并烘焙植物色调，保留像素采样和镂空；预览不复现资源包的连接纹理、PBR、动画或 Minecraft 光影。贴图加载失败时恢复代表色，不影响转换与导出。

维护者可从获许可的资源包重新生成图集；本地游戏 JAR 仅提供方块状态和模型 JSON：

```sh
python scripts/build-textures.py "Pixel Perfection 26.3-97.1.zip" "路径/26.3.jar"
```

## 验证真实模型

```sh
node --experimental-strip-types scripts/verify-model.ts "模型.glb" "结果.schem"
```

脚本按 256 格转换，写出 `.schem` 和检查报告，并用独立 NBT 读取器逐格核对空气、完整方块、上下半砖及楼梯的朝向、上下位置与拐角。报告明确记录是否已在 Axiom 内验证；格式检查通过不等于已在游戏中验收。

展示架版建筑样本：256×256×150，完整方块 1,120,073、下半砖 34,137、上半砖 35,594、楼梯 54,548、展示架 72,479、空气 8,513,569。此前完整方块与半砖版已由用户在 Axiom 中确认可正常导入；新增形状版单独导出并记录验证状态。

## 字体

品牌使用 Minecrafter Alt，固定界面文案使用江西拙楷，输入值、材质名称、方块名称与处理状态使用钉钉进步体，均本地加载。江西拙楷按当前界面文案裁切为约 161 KiB 的 WOFF2；钉钉进步体保留来源完整字集（约 985 KiB），自定义名称中未收录的字符由系统字体补充。字体说明见 `public/fonts/NOTICES.txt`。

维护者更新界面文案或材质库后，可用 Python + fonttools / Brotli 重新裁切；这些仅是离线工具，不是网页依赖：

```sh
python scripts/subset-fonts.py "DingTalk-JinBuTi.woff2" "Minecrafter.Alt.ttf" --ui "jiangxizhuokai.ttf"
```
